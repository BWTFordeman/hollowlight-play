# Hollowlight

A little autumn world with eight playful activities, original procedural art and sound, and rooms for up to four friends.

[Play Hollowlight](https://bwtfordeman.github.io/hollowlight-play/)

Desktop browser. WASD or arrows to wander, E to interact, Space to play, M for the journal. Use Bring a friend to share an invitation. The host must keep the game open and visible. Progress lasts for the current visit.

This repository contains the compiled website only. Development source is maintained privately. Browser-delivered assets remain downloadable. Third-party notices are included in THIRD-PARTY-NOTICES.txt.
